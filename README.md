# Android Auto Research & Analysis Workspace

Tài liệu, mã nguồn phân tích dịch ngược (reverse-engineering), công cụ và tài nguyên nghiên cứu Android Auto.

## Danh mục tài liệu & mã nguồn nghiên cứu
- **aa-jadx**, **aa-17.5-jadx-analysis**, **aa-jadx-target**: Phân tích mã nguồn dịch ngược của Android Auto (Google).
- **waze-analysis**: Phân tích tích hợp Android Auto trên ứng dụng Waze.
- **wyn-analysis**, **wyn-audit-20260906**: Phân tích ứng dụng Wyn Auto & giao thức camera / cảnh báo giao thông.
- **screenonauto-decoded**: Phân tích cơ chế giữ màn hình / wake lock trên ô tô.
- **CarStream-analysis**: Phân tích luồng video stream trên Android Auto.
- **tools**: Các công cụ hỗ trợ phân tích (Blutter, JADX, scripts).
- **Scripts**: Các tập lệnh tự động kết nối DHU, test wifi, phân tích UI (`start-android-auto.ps1`, `start-android-auto-wifi.ps1`, `carweb-ui.xml`...).
